API Integration & Developer Documentation

Overview & Quick Start

Integrate our Virtual Number OTP Allocation API directly into your automated software, Telegram bots, or Python scripts. Our REST API accepts standard JSON POST requests and returns instant allocations with real-time status.

Base URL & Authentication

Base URL: http://localhost:8000/api/get-number.php
HTTP Method: POST
Content-Type: application/json

POST 1. Get / Request Virtual Number

/api/get-number.php

Requests a new virtual phone number for a specific service and country.

curl -X POST "http://localhost:8000/api/get-number.php" \ -H "Content-Type: application/json" \ -d '{ "country": "261", "service": "wa" }'
import requests url = "http://localhost:8000/api/get-number.php" payload = { "country": "261", # 261 = Madagascar, 44 = UK, any = Any Country "service": "wa" # wa = WhatsApp, tg = Telegram, etc. } response = requests.post(url, json=payload) data = response.json() print("Allocated Number:", data["zenex_response"]["data"]["number"])
const response = await fetch('http://localhost:8000/api/get-number.php', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ country: '261', service: 'wa' }) }); const result = await response.json(); console.log('Allocated Phone Number:', result.zenex_response.data.number);
